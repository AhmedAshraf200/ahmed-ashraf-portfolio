# Ahmed Ashraf — Portfolio Website

Personal portfolio website for **Ahmed Ashraf**, a Junior .NET Developer based in Cairo, Egypt. The site showcases my education, work experience, skills, and projects, with a downloadable CV and direct contact links.

**Live Demo:** [your-live-link-here](#)

![Portfolio Preview](img/preview.png)

## ✨ Features

- **Responsive design** — fully adapts to desktop, tablet, and mobile screens
- **Light / Dark mode** with saved preference (persists across visits using `localStorage`)
- **Smooth scroll navigation** between sections
- **Scroll-triggered animations** powered by AOS (Animate On Scroll)
- **Animated skill bars** that fill in as they enter the viewport
- **Interactive mouse-glow cursor effect** for a modern feel
- **Typing effect** on the hero subtitle
- **Downloadable CV** directly from the homepage
- **Sections included:**
  - About Me (bio, education, languages)
  - Work Experience (timeline of internships and roles)
  - Services (what I offer as a developer)
  - Skills (categorized: backend, databases, architecture, tools, security)
  - Projects (with GitHub links)
  - Contact

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom properties (CSS variables) for theming, animations, and responsive layout
- **JavaScript (Vanilla)** — theme toggle, scroll effects, typing animation, IntersectionObserver-based animations
- **[Bootstrap 5](https://getbootstrap.com/)** — grid system and base UI components
- **[AOS](https://michalsnik.github.io/aos/)** — scroll animations
- **[Font Awesome](https://fontawesome.com/)** — icons

## 📁 Project Structure

```
├── index.html      # Main page markup
├── style.css       # Custom styles, theme variables, animations
├── script.js       # Theme toggle, AOS init, scroll & UI interactions
└── img/            # Images, icons, and downloadable CV
```

## 🚀 Running Locally

No build step or dependencies to install — it's a static site.

```bash
git clone https://github.com/AhmedAshraf200/ahmed-ashraf-portfolio.git
cd ahmed-ashraf-portfolio
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# using Python
python -m http.server 8000

# or using VS Code's Live Server extension
```
